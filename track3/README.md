# HY-489 · Track 3 · Metformin and body weight

Our group's project. Everything lives in this folder; the data is the one copy in `../labs/lab01/data/`.

## Reproduce

Python 3, standard library only. From a fresh clone of this repository:

```
cd track3
python3 feasibility.py      # counts used to choose the question
```

More steps (`dataset.py`, `analysis.py`) will be added as they are written.

## Files

| File | What |
|---|---|
| `PLAN.md` | one-page plan |
| `protocol.md` | target trial protocol |
| `amendments.md` | every change to the protocol after it was committed |
| `phenotypes/` | computable phenotypes with their codes |
| `outputs/` | every table and figure in the report |
| `CONTRIBUTIONS.md` | who did what, tools used, signed |
